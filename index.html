01 / ABOUT ME

Turning data into
something useful.

Saya lulusan S1 Sistem Informasi Universitas Amikom Yogyakarta dengan fokus dan pengalaman di bidang pengolahan data dan Data Engineering.

Saya memiliki pengalaman menangani kueri kompleks, mengembangkan proses ETL, serta mengolah dan mentransformasi data menggunakan SQL, PL/SQL, PL/pgSQL, Python, dan berbagai teknologi data processing.

Dalam pekerjaan, saya terlibat dalam proses ingestion, data cleansing, standardisasi, dan pengelolaan data pada alur data warehouse. Saya menyukai pemecahan masalah teknis dan membangun proses yang efisien, terstruktur, serta mudah dipelihara.
