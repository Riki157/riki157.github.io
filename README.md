# Data Engineer Portfolio

Website portfolio one-page dengan tema dark modern. Dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan secara lokal
1. Extract folder project.
2. Buka `index.html` langsung di browser, atau jalankan local server:
   ```bash
   python -m http.server 8000
   ```
3. Buka `http://localhost:8000`.

## Sebelum dipublikasikan
- Ganti `your.email@example.com` pada `index.html` dengan email yang ingin ditampilkan.
- Ganti tautan GitHub dan LinkedIn dengan profil milikmu.
- Periksa kembali deskripsi pengalaman dan skill agar sesuai dengan pengalaman yang benar-benar bisa kamu jelaskan.
- Kartu project saat ini adalah contoh/demo. Tambahkan repository publik setelah project demonstrasi selesai dibuat.
- Jangan masukkan token, password, hostname, IP, data, atau source code rahasia milik perusahaan.

## Struktur
- `index.html` — konten dan struktur halaman.
- `style.css` — tampilan, layout, dan responsive design.
- `script.js` — menu mobile, animasi reveal, dan tahun footer.

## Deploy ke GitHub Pages
1. Buat repository GitHub baru, misalnya `data-engineer-portfolio`.
2. Upload ketiga file (`index.html`, `style.css`, `script.js`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu proses deployment selesai. GitHub akan menampilkan URL website di halaman Pages.
